## 3. 后台管理系统

- [ ] 在预发布环境配置 CloudBase 环境 ID。
- [ ] 验证四类表单编辑、保存、并发冲突、发布、版本历史和手机预览。
- [ ] 发布一份测试模板，确认新版本不可修改，修改草稿不影响线上版本。
- [ ] 验证记录详情使用提交时版本，CSV 必须限定空间类型和版本且包含 UTF-8 BOM。
- [ ] 重新运行 `npm run build` 后再更新后台托管。

## 4. 小程序

- [ ] 在体验版验证远程、缓存、内置三级回退。
- [ ] 验证旧版草稿“继续旧版／使用最新版”。
- [ ] 验证图片和文件上传失败后的重试不会重复上传已成功文件。
- [ ] 验证匿名 OPENID 提交、重复点击幂等、历史版本服务端校验和非法 `fileID` 拒绝。
- [ ] 微信开发者工具基础库 `3.11.2` 完成预览及至少一台 iOS、一台 Android 真机验证。

## 5. 上线与回退

- [ ] 取得用户明确的生产部署授权。
- [ ] 先部署云函数和数据库配置，再部署后台，最后提交小程序审核。
- [ ] 小程序发布前保留内置模板；即使远程故障仍可填写本地版本。
- [ ] 若后台异常，停止发布新模板即可；已有发布版本和历史提交保持不变。
- [ ] 若小程序异常，回退小程序版本，不删除三个新集合或不可变版本。
