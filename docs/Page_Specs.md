# 页面内容规划（Page Specs）

> 本文档描述光乙共创平台 Web 端各页面的具体内容区块与核心元素，供设计、开发、内容团队对齐使用。

## 1. 公开页面

### 1.1 落地页 `/`

| 区块 | 具体内容 |
|---|---|

| **Footer** | Logo、快速链接（各主页面）、联系方式、ICP 备案号、公安联网备案号、用户协议、隐私政策 |

## 2. 工具类页面

### 2.1 工具箱入口 `/tools`

> **设计风格指南**：工具箱作为专业灯光设计的辅助入口，Web 端布局应摒弃移动端简单的纵向堆叠，采用类似 Apple 或现代 SaaS 的 **Bento Box（便当盒）网格布局**。通过大面积圆角卡片、高品质实景底图覆盖与半透明磨玻璃（Glassmorphism）效果，凸显「高级感」与「专业性」。

| 区块 | 具体内容 |
|---|---|
| **页面头部** | 极简大标题「工具箱」与副标题「照明设计专业辅助工具」|
| **主打工具（Bento 大卡片）** | **照度计算器**：占据大网格，背景采用高质量的光度分布伪色图（类似 DIALux 计算结果），左下角显示醒目文字「照度计算器」，提供一键进入计算流的按钮。<br>**色温选择器**：并排的另一个大网格，背景采用从暖到冷渐变的实景射灯效果图，醒目文字「色温选择器」 |
| **辅助工具（Bento 长条卡片）** | **灯光认知测试**：占据下方长条形网格，背景采用深色系阅卷/草图实景，文案「灯光测试 / 5分钟测测你的灯光设计认知阶段」，右下角配标志性浮动操作按钮（如带闪电图标的圆形 FAB） |
| **交互细节** | Hover（悬停）任意工具卡片时，背景图呈现轻微缩放放大（Scale）与变暗效果，文字同时上浮，按钮出现光晕反馈 |

### 2.2 色温选择器（表单填写页） `/tools/color-temp`

| 区块 | 具体内容 |

| **参数填写表单** | **空间选择**：单选按钮组/下拉框（客厅、卧室、餐厅、厨房、卫生间、书房、阳台等）<br>**主要材质色彩**：颜色拾色器/色卡组（深色系/浅色系/木色系等，还原小程序逻辑）<br>**风格偏好**：单选组（现代简约、法式侘寂、极简奶油、新中式等）<br>**采光情况**：单选组（采光极好、正常、采光较差） |
| **操作区** | **计算按钮**：「生成专属色温方案」CTA 按钮（点击后跳转或就地展开结果）<br>**历史入口**：「查看历史记录」链接 |

### 2.3 色温推荐结果 `/tools/color-temp/result`

| 区块 | 具体内容 |

| **相关灯具推荐** | 横向卡片展示适合该色温的精选灯具，点击可跳转至商城详情 |
| **底部操作栏** | **分享**：生成长图以便分享给客户或朋友<br>**重算**：「重新计算」返回上一页表单 |

### 2.5 照度计算器 `/tools/illuminance`

| 区块 | 具体内容 |
|---|---|
| **计算模式切换 Tab** | 三种模式：① 已知单灯流明→计算灯数（Lamp→Count）② 已知灯数→计算照度（Count→Lux）③ 已知照度目标→反算灯具参数（Lux→Params） |
| **输入表单** | 房间长（m）、房间宽（m）、层高（m）、目标照度（lux）、单灯光通量（lm）、维护系数、空间类型下拉（影响利用系数）、顶面/墙面反射率选择 |
| **利用系数智能选择** | 层高 × 空间色彩组合自动带出 CU 建议值，支持手动覆盖 |
| **实时结果区** | 所需灯具数量（大字显示）+ 实际照度复核值 + 每平米灯具数参考 |
| **操作按钮** | 生成 PDF 报告、保存本次计算、Excel 导入参数（Pro）、历史记录 |
| **帮助入口** | 公式说明弹窗 / 跳转 `/tools/illuminance/help` |

### 2.6 计算结果报告 `/tools/illuminance/result`

| 区块 | 具体内容 |
|---|---|
| **报告头部** | 项目名称（可编辑）、计算时间、计算人 |
| **输入参数汇总表** | 所有输入值以表格呈现 |
| **计算结果** | 灯具数量、实际照度、功率密度（W/㎡）等核心数值 |
| **公式推导说明** | 展示完整计算过程（利用系数法公式） |
| **操作** | 下载 PDF（A4 排版）、复制分享链接、重新编辑 |

### 2.7 照度计算历史 `/tools/illuminance/history`

| 区块 | 具体内容 |
|---|---|
| **历史列表** | 项目名称 + 空间尺寸摘要 + 计算结果摘要 + 时间 + 「查看/重新编辑/删除」操作 |

### 2.8 公式说明 `/tools/illuminance/help`

| 区块 | 具体内容 |
|---|---|
| **三种模式说明** | 各模式对应的公式、参数解释、适用场景 |
| **利用系数参考表** | 不同房间类型 + 层高 + 反射率 → CU 参考值对照表 |
| **常用照度标准** | 住宅/办公/商业/酒店等场景的推荐照度范围 |
