## 2. 产品概述

### 2.1 产品名称与定位
**产品名称**：光乙共创平台 (Web 版)
**产品定位**：一站式高端灯光设计与服务撮合平台。集照明设计资源、智能计算工具、精选灯具商城、专业课程与灵感图库于一体，为业主与专业照明设计师搭建高品质的双边共创生态。

### 2.2 产品愿景与使命
**愿景**：让每个人都能轻松获得专业级的光环境体验，成为行业内最具影响力的灯光设计数字化基础设施。
**使命**：用科技（AI与专业计算）和设计的力量，连接需求与专业，提升空间照明品质。

### 2.3 价值主张与独特卖点 (USP)
- **专业工具普惠化**：提供 AI 色温推荐（RAG+GLM）、专业照度计算工具的 Web 版，让复杂的照明工程计算变得可视化、简单化。
- **高品质双边市场**：严格准入的照明设计师池与高端业主需求的无缝对接。
- **Apple 级美学体验**：坚持 Apple 官方级极简、沉浸式的 UI/UX 设计语言，提供极致的跨屏浏览体验。

### 2.4 目标平台列表
- **Web 端 (PC)**：支持主流现代浏览器 (Chrome, Edge, Safari, Firefox)。主要面向需要大屏操作、复杂计算、图纸预览及后台管理的用户场景。
- **Web 端 (移动 H5)**：适配主流手机浏览器与微信内嵌浏览器。主要面向碎片化时间的内容浏览、简单需求发布与订单跟进。

### 2.5 产品核心假设
- **假设 1**：部分专业设计师和B端业主在进行方案对比、上传/下载图纸（CAD/DIALux）时，重度依赖 PC 大屏，小程序的纯移动端体验无法满足深度办公需求。
- **假设 2**：Web 端的 SEO（搜索引擎优化）能力能为平台带来可观的自然搜索流量（尤其是对灯光知识、设计课程有需求的用户）。

### 2.6 商业模式概述
- **服务抽佣/服务费**：撮合业主与照明设计师，收取平台服务费。
- **内容变现**：专业灯光设计课程视频售卖。
- **SaaS 工具增值**：照度计算工具高级版（Pro）、高级工具包订阅。
- **电商零售**：精选灯具、配件的销售利润。

## 3. 用户研究

### 3.1 目标用户画像
#### 3.1.1 需求方（业主/公装甲方）
- **特征**：25-45岁，具有较高审美和一定购买力，正在进行房屋装修或商业空间改造。
- **痛点**：不懂灯光搭配，怕“翻车”；找不到靠谱、审美在线的独立照明设计师。
- **目标**：寻找灯光设计灵感，采购专业级灯具，预约设计师。

#### 3.1.2 供给方（照明设计师/灯光顾问）
- **特征**：22-40岁，掌握 DIALux 等专业软件，具备一定的项目落地经验。
- **痛点**：获客成本高；与客户沟通方案效率低；缺乏统一的接单与项目管理工具。
- **目标**：获取高质量订单，提升个人品牌知名度，利用便捷工具提高作图/计算效率。

### 3.2 用户场景分析
- **核心场景 1 (PC 端创作与服务)**：设计师在 PC 端登录，使用“照度计算工具 Pro”为客户快速计算所需灯具数量，生成 PDF 报告；并在需求大厅接单，上传 DIALux 方案与 CAD 图纸。
- **核心场景 2 (H5 浏览与决策)**：业主通过搜索引擎检索到“色温怎么选”，进入平台 H5 页面体验“AI 色温助手”，随后浏览“灵感库”，最终被引导注册并发布灯光设计需求。

## 4. 市场与竞品分析

### 4.1 行业趋势分析
- **智能化与专业化**：无主灯设计普及，消费者对光环境的要求从“亮”向“美与健康”转变。
- **AIGC 渗透**：AI 在空间设计领域的应用逐渐成熟，通过自然语言生成照明方案成为可能。

### 4.2 竞争格局分析
- **直接竞品**：住小帮、好好住（大而全，照明细分不够专业）；部分独立灯光设计工作室官网（缺乏平台化能力）。
- **差异化策略**：聚焦“光”这一个垂直切面，用顶级的美学设计、专业的计算工具和 AI 赋能形成强护城河。

## 5. 产品功能需求

### 5.1 功能架构与模块划分
Web 端功能架构划分为六大核心模块：**工作台（首页）、发现（灵感与课程）、工具（计算器与AI助手）、商城、服务大厅（接发单）、个人中心**。

### 5.2 核心功能详述

#### 5.2.1 账户与认证中心
- **功能描述**：作为用户，我想要通过手机号、微信扫码等多种方式注册/登录，以便在多端同步我的数据。
- **功能逻辑**：
  - 支持手机号+验证码登录/注册，作为跨端数据合并的核心标识。
  - PC 端支持微信扫码登录（需接入微信开放平台 Web 授权）。
  - H5 支持微信环境内静默授权登录。
  - 支持多角色认证：普通业主、专业照明设计师（需提交相关资质、过往作品及 DIALux 报告供审核）。

#### 5.2.2 官网主页与服务展示 (Products Page)
- **功能描述**：作为新访客，我希望通过直观、高端的界面了解平台的灯光设计服务、精选内容及购买入口。
- **功能逻辑**：
  - Apple 风格横向大卡片滚动/网格展示（灯具产品、设计流程、课程入口等）。
  - 《灯光设计服务说明书》长单页重构，支持大图查看交付标准、客户评价，提供一键预约入口。
  - 响应式导航栏支持快速跳转：商城、探索、课程、工具、服务说明。

#### 5.2.3 深入探索与内容社区 (Explore)
- **功能描述**：作为专业人士或爱好者，我希望了解最新的灯具测评、照明设计技巧、Today at Apple 式的线下活动。
- **功能逻辑**：
  - 资讯文章展示（图文、视频内嵌），支持富文本排版。
  - 分类浏览：摄影技巧、智能家居、商业照明案例等。
  - SEO 友好的静态文章 URL，支持社交平台一键分享。

#### 5.2.4 灵感库与知识库 (Gallery / 响应式重构)
- **功能描述**：作为寻找灵感的用户，我希望在大屏上以更广阔的视野浏览灯光实景图和标签云。
- **交互要求**：
  - PC 端：采用瀑布流布局，左侧/顶部提供高级筛选面板（空间、风格、色温等）。原小程序的 Torus 六边形无限滚动标签云在 PC 端可通过鼠标拖拽或滚轮实现 3D 视角交互。
  - H5 端：保留滑动体验，支持跟手拖拽与全屏预览缩放。

#### 5.2.5 AI 色温助手与照明计算工具 (Pro 级 Web 体验)
- **功能描述**：作为设计师，我希望在 PC 端进行高效的照度计算、色温匹配和多灯具对比。
- **功能逻辑**：
  - **免费版/付费版权限控制**：继承小程序的 `toolkit_purchase_check` 鉴权逻辑。
  - **Web 端增强体验 (照度计算器)**：
    - 支持 Excel 格式批量导入导出灯具参数。
    - 提供更复杂的表单视图（支持 Tab 键快速切换输入框）。
    - 空间类型与利用系数（层高 × 色彩）智能选择下拉树。
    - 生成专业的 A4 尺寸 PDF 报告并支持一键下载。
  - **AI 色温助手**：调用 RAG+GLM 模型，左侧对话框输入空间场景，右侧实时生成方案大纲与推荐参数，主模型失败时自动降级到基础模型。

#### 5.2.6 课程系统与白名单授权
- **功能描述**：作为学员，我希望在电脑上观看高清灯光设计课程，方便我同时做笔记或实操软件。
- **功能逻辑**：
  - 课程列表与详情大纲展示，免费试看片段。
  - Web 端定制视频播放器：支持清晰度切换 (480p/720p/1080p/4K)、倍速播放、记忆播放进度。
  - 防盗链机制：采用 HLS 流媒体切片，加上 Token 防盗链，防止视频被轻易下载。
  - **白名单机制同步**：用户绑定手机号后，自动触发白名单校验。如果在后台（如千聊等其他平台）已购买，自动生成 Web 端的 0 元虚拟订单并解锁观看权限。

#### 5.2.7 商城、购物车与支付 (Mall & Payment)
- **功能描述**：作为消费者，我希望在 Web 上流畅地购买实体灯具、工具包和虚拟课程。
- **功能逻辑**：
  - 完整的商品浏览、规格（SKU）选择。
  - 购物车管理（加入、移除、修改数量、批量选择结算）。
  - **跨端支付**：
    - PC 端支付：生成微信支付/支付宝二维码（Native 支付），前端通过 WebSocket 或轮询获取支付成功状态。
    - H5 端支付：在微信内唤起 JSAPI 支付；在外部浏览器唤起 H5 支付或跳转支付宝。

#### 5.2.8 订单管理与售后退款 (Order & Refund)
- **功能描述**：作为消费者，我需要查看我的所有类型订单进度，并在需要时申请退款或退货。
- **功能逻辑**：
  - 统一订单列表：支持分类筛选（实体商品、课程订单、工具包订单）。
  - 订单状态流转可视化（待支付、已支付、已发货、已完成、已关闭）。
  - **退款与售后流程**：
    - 仅退款（虚拟商品/未发货）：申请 -> 商家审核 -> 微信/支付宝原路退回。
    - 退货退款（实物）：申请 -> 商家审核 -> 用户填写退回物流 -> 商家确认收货 -> 退款。
  - Web 端提供上传凭证图片功能（支持拖拽上传，单次最多 9 张）。

#### 5.2.9 需求大厅与设计师协作空间 (Designer Hub)
- **功能描述**：作为业主，我可以在线发布详细图纸；作为设计师，我可以接单并交付大型图纸文件。
- **功能逻辑**：
  - **业主端**：
    - 发布详细需求（面积、照度目标、控制方式、预算）。
    - **押金机制**：缴纳押金让需求获得“优先”标志，客服与设计师优先对接，订单完成后自动退还。
    - 挑选设计师、预约服务、评价打分。
  - **设计师端 (Web 核心生产力)**：
    - 需求大厅过滤与抢单面板。
    - 大文件直传组件：支持大于 100MB 的 CAD、DIALux (`.evo`) 格式工程文件上传。
    - 项目阶段流转看板（概念方案 -> 布灯图 -> 计算报告 -> 清单/报价 -> 验收）。

#### 5.2.10 全局搜索与搜索历史 (Search)
- **功能描述**：作为用户，我想要快速定位我想要的商品、课程、文章或工具。
- **功能逻辑**：
  - 顶部常驻搜索栏，支持实时联想输入。
  - 混合搜索结果页：分栏展示（商品、课程、探索文章、服务）。
  - 搜索历史记录（同步到云端或本地 LocalStorage）。

#### 5.2.11 个人中心 (Profile / Dashboard)
- **功能描述**：作为用户，我可以在这里管理我所有的个人资产和设置。
- **功能逻辑**：
  - 基础设置：头像修改、昵称修改、收货地址管理。
  - 资产管理：我的发票、我的收藏（灵感图片、文章、商品）。
  - 客户支持：一键联系微信客服、查看常见问题、提交意见反馈。

#### 5.2.12 运营与管理后台 (Admin Panel - 面向平台运营人员)
*(注：通常管理后台会独立为一个系统，但在此列出需支撑 Web 端的必要管理功能)*
- **功能逻辑**：
  - 白名单批量导入管理（CSV/Excel）。
  - 订单审核与售后打款处理。
  - 押金人工退款兜底机制。
  - 案例、评价、交付标准的增删改查。
  - 数据统计大盘（交易额、访问量、各服务转化率）。

## 6. 用户流程与交互设计指导

### 6.1 核心用户旅程 (需求发布流程)
1. **访问**：用户通过搜索引擎访问 Web 官网。
2. **体验**：免登录使用简单的 AI 色温测算。
3. **转化**：提示需要更精准的设计，引导扫码登录/注册。
4. **发布**：填写详细需求（空间、面积、预算），上传户型图附件。
5. **匹配与支付**：选择心仪设计师，系统生成订单，展示聚合支付二维码。

### 6.2 设计指导与规范
- **设计语言**：延续 Apple 官方风格。深色模式优先，强调卡片式UI、大圆角（20px/10px响应）、毛玻璃模糊效果。
- **响应式断点**：
  - Desktop: `> 1024px` (最大宽度居中，多列布局，侧边栏导航)
  - Tablet: `768px - 1024px` (过渡布局)
  - Mobile: `< 768px` (类似小程序布局，底部或顶部汉堡菜单)

## 7. 非功能需求

### 7.1 性能需求
- 首屏加载时间（FCP）：Web 端需控制在 1.5 秒以内。
- 视频加载：首帧缓冲时间 < 1s。
- 采用 SSR（服务端渲染）或 SSG 技术，提升搜索引擎爬虫抓取效率。

### 7.2 安全需求
- 通讯安全：全站强制 HTTPS。
- 数据安全：支付回调必须经过严密的签名验证（对接现有的微信支付 V3 API 云函数）。
- 接口防刷：短信验证码、AI 接口需增加图形验证码防刷机制。

### 7.3 合规性需求
- 提供 ICP 备案号、公安联网备案号展示（底部 Footer）。
- 新用户注册强制要求勾选《用户协议》与《隐私政策》。

## 8. 技术架构考量

### 8.1 推荐技术栈
- **前端框架**：Next.js (React) 或 Nuxt.js (Vue) — 利于 SEO 和首屏性能。
- **样式方案**：Tailwind CSS，便于快速实现响应式和深色模式。
- **状态管理**：Zustand (React) 或 Pinia (Vue)。
- **后端服务**：继续复用现有的 CloudBase (微信云开发) 云函数和云数据库。通过 `@cloudbase/js-sdk` 接入 Web 端。

### 8.2 系统集成
- **统一身份认证 (SSO)**：Web 端需要和微信小程序的 `OpenID/UnionID` 打通，核心是以 **手机号** 作为跨端合并用户的唯一标识 (UnionID 作为辅助)。

## 9. 验收标准汇总
- **功能验收**：Web 端所有模块功能与 PRD 描述一致，主流程（登录、购物、计算器、音视频、需求流转）无阻塞。
- **响应式验收**：在主流分辨率 (1920, 1440, 1024, 375) 下布局无错乱。
- **性能验收**：Lighthouse 性能评分 > 85。

## 10. 产品成功指标 (KPI)
- **流量指标**：Web 端月独立访客 (UV)。
- **转化指标**：Web 端到注册用户的转化率；从免费计算器到购买工具包的转化率。
- **活跃指标**：工具类功能（计算器、AI 助手）的 Web 端周活跃使用频次。
