# 产品评估指标框架 (Metrics Framework) - Web 端

## 1. 指标框架概述
为了准确评估光乙共创平台在扩展至 Web 端后的表现，验证我们的产品核心假设，本框架基于 AARRR（海盗模型）和 HEART 框架，定义了衡量 Web 端产品成功与否的量化标准。

## 2. 北极星指标 (North Star Metric)
**北极星指标：全平台产生有效交易的转化总额 (GMV) 及其增速。**
*定义*：包含商城灯具购买、Pro 工具包购买、课程售卖以及设计服务平台抽佣的总和。
*选择依据*：Web 端的终极目标是补全办公场景，提升客单价较高、决策周期较长（如大型灯光设计服务、批量课程采购）的交易成功率。

---

## 3. AARRR 指标体系详述

### 3.1 获取 (Acquisition) - 流量与来源
*目标：通过 Web 端的 SEO 和外链优势吸引新流量。*
- **Web 端 MAU / WAU (月/周活跃用户数)**。
- **自然搜索流量占比 (Organic Search %)**：通过百度/Google 搜索关键词（如“照度计算”、“灯光色温推荐”）进入网站的流量。
- **页面首屏跳出率 (Bounce Rate)**：衡量着陆页（官网、服务说明书页）的吸引力与加载性能。

### 3.2 激活 (Activation) - 账号转化
*目标：将访客转化为注册用户。*
- **注册/登录转化率**：访问 Web 端 -> 成功使用手机号或扫码完成登录的比例。
- **关键工具激活率**：访客进入 Web 端后，成功进行一次“AI 色温计算”或“免费照度计算”的比例。

### 3.3 留存 (Retention) - 持续价值
*目标：用户在平台上找到持续使用的价值（尤其是专业设计师）。*
- **次周/次月留存率**。
- **Pro 工具包活跃度**：已购买工具包的用户，每周在 PC 端使用高级计算器的次数。

### 3.4 变现 (Revenue) - 商业转化
*目标：产生收入。*
- **Web 端客单价 (AOV)**：与小程序端对比，验证 PC 端是否更容易促成大额交易。
- **从工具到付费的转化率**：使用免费计算器的用户 -> 购买 Pro 工具包的转化漏斗。
- **购物车放弃率**：Web 端发起支付但未成功扫码支付的比例。

### 3.5 推荐 (Referral) - 自发传播
*目标：口碑传播。*
- **PDF 报告生成与分享次数**：设计师在 PC 端生成计算报告后分享给客户的频次（报告自带平台 Logo 与引流二维码）。

## 4. 针对 Web 端的特色评估指标 (HEART)

| 维度 | 目标 | 核心指标 |
| :--- | :--- | :--- |
| **H (Happiness) 愉悦度** | 用户对 PC 端视觉与体验满意 | NPS (净推荐值)，用户反馈工单中的正面评价比例。 |
| **E (Engagement) 参与度** | 用户在专业工具和视频上的沉浸感 | 课程视频的平均完播率 (Web 端)；单次会话的平均停留时长。 |
| **A (Adoption) 接受度** | 新上线的 PC 工作台被设计师接纳 | 需求大厅中 Web 端的接单比例 vs 小程序接单比例；Web 端大图纸上传成功率。 |
| **R (Retention) 留存率** | 设计师将平台作为核心生产力工具 | 核心设计师（每月接单>2次）的平台留存率。 |
| **T (Task Success) 任务完成率**| Web端顺畅完成复杂表单与计算 | 计算器表单的无错提交率；支付二维码成功扫码完成率。 |

---

## 5. 指标监测计划

### 5.1 数据采集与埋点
- **基础分析**：接入百度统计或 Google Analytics 获取基础的 PV/UV、跳出率和来源渠道。
- **行为埋点**：在“核心转化按钮”（如：点击“计算结果”、点击“扫码支付”、“生成PDF报告”、“上传 CAD 图纸”）上进行自定义事件埋点。

### 5.2 报告频率与复盘
- **实时/日级别**：关注交易失败率、接口报错率、扫码支付掉单情况。
- **周级别**：复盘核心转化漏斗（访问 -> 注册 -> 体验工具 -> 购买转化）。
- **月级别**：评估 SEO 流量增长趋势、客单价对比分析及整体北极星指标达成进度。
