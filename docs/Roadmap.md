# 产品路线图 (Roadmap) - 光乙共创平台 Web 端

## 1. 路线图概述
本路线图规划了光乙共创平台从纯微信小程序形态拓展至全平台 Web 端的演进路径。我们将采用敏捷迭代、小步快跑的策略，优先迁移核心的流量承接工具与内容模块，逐步实现重度办公和完整交易闭环。

## 2. 版本规划策略
- **Phase 1 (MVP)**: **流量与工具前哨**。核心目标是建立 Web 端入口，支持 SEO 引流，提供免登录/轻登录的专业工具与内容展示。
- **Phase 2 (v2.0)**: **商业化与闭环**。打通支付、账号体系，实现全平台课程购买与商城交易。
- **Phase 3 (v3.0)**: **专业级双边工作台**。全面强化设计师 PC 端办公体验，实现需求流转、大文件协作与项目管理功能。

---

## 3. 详细版本规划与功能优先级

### Phase 1: MVP 版 - 品牌阵地与核心工具 Web 化 (预计耗时: 1.5个月)
**目标**: 建立官网，通过 SEO 获取自然搜索流量，将高价值的计算工具和平铺内容开放给 PC 用户。

| 功能模块 | 优先级 | 描述 |
| :--- | :--- | :--- |
| **基础框架与官网** | P0 | 搭建 SSR 框架 (Next.js/Nuxt)，实现响应式布局和 Apple 风格 UI 还原。包含平台介绍、服务说明书页。 |
| **账号体系 (轻量)** | P0 | 手机号+验证码注册/登录。打通云数据库。 |
| **工具: 照度计算器** | P0 | 免费版计算器的 Web 化，适配 PC 宽屏表单交互。 |
| **工具: AI 色温助手** | P1 | RAG+GLM 模型的 Web 端对话式交互界面。 |
| **灵感库 (只读)** | P1 | 瀑布流布局的灵感图库展示，支持基础标签筛选。 |
| **课程展示 (无播放)** | P2 | 展示课程大纲与详情，引导去小程序购买/观看。 |

### Phase 2: v2.0 版 - 交易闭环与沉浸式学习 (预计耗时: 1.5个月)
**目标**: 在 Web 端完成商业闭环，不再强制依赖小程序进行变现。

| 功能模块 | 优先级 | 描述 |
| :--- | :--- | :--- |
| **扫码/H5 支付系统** | P0 | 接入微信/支付宝的 Web 端 Native 支付（二维码/JSAPI）。 |
| **电商商城与购物车** | P0 | Web 端完整购物流程（加购、结算、地址管理、订单状态展示）。 |
| **计算器 Pro 版** | P0 | 付费工具包校验，PC 端特有功能（批量导入导出、PDF 报告生成）。 |
| **课程视频播放器** | P0 | 支持清晰度切换的 Web 视频播放器，购买状态校验与防盗链。 |
| **白名单授权同步** | P1 | 手机号登录后，自动同步并在 Web 端激活已授权的白名单课程。 |
| **售后与退款流程** | P2 | Web 端提交退款申请、上传凭证与流程查看。 |

### Phase 3: v3.0 版 - 专业设计工作台 (预计耗时: 2个月)
**目标**: 彻底释放 PC 生产力，打造设计师与高端业主的在线协作空间。

| 功能模块 | 优先级 | 描述 |
| :--- | :--- | :--- |
| **需求大厅与抢单** | P0 | 设计师专属 PC 看板，接单、筛选、抢单。 |
| **大文件协作存储** | P0 | 支持 CAD、DIALux 工程文件、海量现场图片的 PC 端上传与管理。 |
| **阶段交付 Kanban** | P1 | 项目进度可视化看板（勘测->布灯->算照度->交付），节点确认与评价。 |
| **押金与保证金体系** | P1 | 需求优先匹配逻辑及押金缴纳退回流程的 Web 端支持。 |
| **数据洞察面板** | P2 | 针对设计师的个人接单数据分析表（转化率、收益、评价分）。 |

## 4. 详细时间线计划 (里程碑)

| 里程碑节点 | 时间节点 (T为启动日) | 关键交付物 |
| :--- | :--- | :--- |
| **Milestone 1: 架构确立** | T + 2 周 | Web 端技术选型落地，CI/CD 跑通，基础组件库与布局组件完成。 |
| **Milestone 2: MVP 发布** | T + 6 周 | 官网主页、服务说明书、AI 助手与免费计算器上线，SEO 基础配置完毕。 |
| **Milestone 3: 交易跑通** | T + 10 周 | 支付接口联调完成，商城流转和工具包购买功能通过测试。 |
| **Milestone 4: v2.0 发布** | T + 12 周 | 课程全量上线，Web 端完整用户账户体系闭环。 |
| **Milestone 5: v3.0 发布** | T + 20 周 | 设计师协作台全面上线。 |

## 5. 资源规划 (初步建议)
- **前端工程师**: 2 名（熟练掌握 React/Vue 及复杂响应式与动画实现）。
- **全栈/后端工程师**: 1 名（负责 CloudBase 云函数 Web 端适配，OSS大文件直传，外部支付网关接入）。
- **UI/UX 设计师**: 1 名（负责小程序到 PC 端宽屏交互的转换设计）。
- **测试工程师**: 1 名（覆盖 PC 各类浏览器及移动端 H5 兼容性测试）。

## 6. 风险管理

| 风险项 | 影响程度 | 发生概率 | 应对策略 |
| :--- | :--- | :--- | :--- |
| **跨端身份合并困难** | 高 | 中 | 核心依赖手机号作为唯一标识。建议在用户通过小程序或 Web 端登录时，强制绑定手机号以便数据归一。 |
| **SEO 效果不达预期** | 中 | 高 | 必须采用 SSR 技术；内容模块（特别是灵感库和文章）需要生成大量优质静态 URL。 |
| **云函数跨域与安全** | 高 | 低 | 及时在腾讯云开发控制台配置合法的 Web 跨域安全域名 (CORS)。 |
| **大屏 UI 照搬移动端** | 中 | 中 | 设计师需重新思考排版，拒绝简单的拉伸。严格执行 PRD 中的响应式重构指导。 |
