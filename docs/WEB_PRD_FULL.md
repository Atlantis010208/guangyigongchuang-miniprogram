# 光乙共创平台 Web 端 - 全功能详细需求文档 (PRD)

## 1. 文档概述
本文档在现有微信小程序版本功能的基础上，为光乙共创平台的 Web 端（PC + H5）提供全量功能的详细定义。Web 端旨在为用户（尤其是 B端业主和专业设计师）提供更高效的大屏交互、文件管理（如CAD/DIALux）和复杂业务流程跟进体验。

## 2. 总体功能架构图

光乙共创平台 Web 端包含以下 8 大核心模块：
1. **公共门户与探索 (Public & Explore)**
2. **用户认证与身份系统 (Auth & Identity)**
3. **个人中心面板 (User Dashboard)**
4. **专业计算与工具箱 (Toolbox & AI)**
5. **知识与课程学习 (Education & Knowledge)**
6. **电商与商城 (Mall & E-commerce)**
7. **设计师生态与工作台 (Designer Workspace)**
8. **需求发布与全生命周期跟进 (Project Workflows)**

---

## 3. 详细功能模块说明

### 3.1 公共门户与探索 (Public & Explore)
本模块面向所有访客，用于引流、品牌展示和全站内容检索。
- **首页 (Home/Splash)**：
  - 幻灯片 Banner 展示最新活动、推荐课程与热门案例。
  - 核心服务快捷入口（寻设计师、看课程、买灯具、用工具）。
  - 精选灵感图库推荐。
- **全局搜索 (Search)**：
  - 顶部常驻搜索框，支持关键字自动联想。
  - **综合搜索结果页**：将商品、课程、文章、问答和设计师分页/分栏展示。
  - **搜索历史与热搜**：支持清除本地搜索记录。
- **灵感图库 (Gallery)**：
  - 瀑布流展示高品质灯光实景案例图片，支持按空间（住宅、商业、办公、酒店）筛选。
- **活动公告 (Activities/Features)**：
  - 平台最新活动、优惠政策的详细图文展示。

### 3.2 用户认证与身份系统 (Auth & Identity)
- **登录与注册 (Login/Register)**：
  - 微信扫码登录（PC端核心流程）。
  - 手机号 + 验证码/密码登录。
  - 强制勾选《用户协议》与《隐私政策》。
- **双端身份切换 (Identity)**：
  - 注册/首次登录时选择身份：**“我是业主”** 或 **“我是设计师”**。
  - 不同身份进入后展现不同的 Dashboard 工作台视图。
- **资质审核与拒绝提醒 (Designer Denied)**：
  - 设计师身份需提交资质，包含审核中、审核拒绝（展示拒绝原因及重新提交入口）页面。

### 3.3 个人中心面板 (User Dashboard - 业主视角为主)
- **总览面板 (Profile Home)**：
  - 展示用户头像、昵称、会员等级状态。
  - 核心数据外显（待办需求数、进行中订单数、购物车商品数）。
- **账户与基础设置 (Account & Settings)**：
  - 编辑个人资料（头像、昵称、性别、联系方式）。
  - 地址管理（增删改查收货地址）。
- **我的需求与项目 (Requests & Appointments)**：
  - 列表查看发布的照明设计需求及当前状态。
  - 预约历史记录。
- **订单与资产管理 (Orders & Assets)**：
  - 商城订单列表（待支付、待发货、待收货、退款/售后）。
  - 我的押金/钱包 (Deposit)。
  - 发票管理 (Receipts) 与开票记录。
- **我的收藏 (Favorites)**：
  - 收藏的商品、课程、灵感图、设计师。
- **会员中心 (Membership)**：
  - 查看当前会员权益（普通用户 vs Pro 订阅）。
  - 会员升级与购买页面。
  - 邀请记录 (Invite History)。
- **客户支持 (Support)**：
  - 意见反馈表单、联系客服入口。

### 3.4 专业计算与工具箱 (Toolbox & AI)
针对专业照明设计提供 Web 端的计算体验（PC 大屏尤其适合图表和数据录入）。
- **工具箱大厅 (Toolbox)**：
  - 展示所有可用工具的卡片列表。
- **AI 色温推荐工具 (Color Temp)**：
  - 输入空间参数与偏好，利用大模型推荐合适的色温。
  - 生成详细的色温推荐结果报告。
  - 历史测算记录 (History) 保存。
- **照度计算器 (Lighting Calc)**：
  - 根据长、宽、高、反射率和目标照度，计算所需灯具光通量或数量。
  - **计算结果 (Calc Result)**：以图表和数据卡片展示参数结论。
  - **帮助中心 (Help)**：图文并茂地解释“灯转照度”、“照度转数量”、“照度转参数”的计算原理。
- **专业水平评测问卷 (Quiz)**：
  - 面向用户的照明基础水平测试。
  - 测试详情、评分结果及历史记录。

### 3.5 知识与课程学习 (Education & Knowledge)
- **课程大厅 (Course Index)**：
  - 线上专业照明课程列表（免费/付费）。
- **课程详情 (Course Detail)**：
  - 课程大纲、讲师介绍、学员评价、购买按钮。
- **视频播放 (Video Player)**：
  - Web 端自适应宽屏播放器，支持章节切换、清晰度调整。
- **照明手册/百科 (Lighting Manual)**：
  - 灯光专业知识 Wiki 词条浏览。
- **节能提示 (Tips/Energy)**：
  - 绿色照明与节能小贴士文章。

### 3.6 电商与商城 (Mall & E-commerce)
- **商城首页 (Mall)**：
  - 灯具、配件、智能控制面板等分类导航及商品推荐。
  - 空间分类馆（Residential, Commercial, Office, Hotel）。
- **商品详情 (Product Detail)**：
  - 多图画廊、规格参数、价格阶梯、用户评价。
  - 加入购物车、立即购买按钮。
- **购物车 (Cart)**：
  - 跨端同步的购物车，支持勾选、数量修改、总价计算。
- **订单交易流程 (Order Flow)**：
  - 订单结算/确认 (Confirm)：选择地址、使用优惠券。
  - 支付环节（支持微信/支付宝 Web 扫码支付）。
  - 支付结果页 (Result)。
- **退款与售后 (Refund)**：
  - 申请退款/退货表单及售后详情追踪。

### 3.7 设计师生态与工作台 (Designer Workspace)
本模块是专为通过审核的设计师打造的 B端工作台。
- **需求大厅 (Designer Home / Demands)**：
  - 瀑布流/列表展示业主发布的公开设计需求。
  - 接单与过滤系统（按面积、预算、空间类型）。
  - 需求详情分析。
- **我的接单与项目 (Designer Projects)**：
  - 已接单的项目列表及详情。
  - **重点功能**：Web 端支持大文件直传（CAD, DIALux 工程文件等），支持版本管理。
- **设计师个人主页管理 (Designer Profile)**：
  - 编辑对外展示的主页信息、服务报价。
- **作品集管理 (Portfolios)**：
  - 添加/编辑图文作品集，PC 端支持批量上传和富文本编辑。
- **通知与邀请 (Notifications & Invites)**：
  - 系统通知、业主定向邀请信息。
- **隐私与安全设置 (Settings/Privacy)**：
  - 设置接单状态（接单中/休息中）、接单阈值等。

### 3.8 需求发布与全生命周期跟进 (Project Workflows)
定义一次“灯光设计服务”的标准履约 SOP，双端（业主与设计师）可通过 Web 同步追踪进度。
- **发布需求 (Publish)**：业主填写预算、偏好、上传户型图。
- **标准服务八阶段 (Flows)**：
  1. **现场勘测 (Survey)**
  2. **概念方案 (Concept)**
  3. **照度计算 (Calc)**
  4. **灯具选型 (Selection)**
  5. **方案优化 (Optimize)**
  6. **施工指导 (Construction)**
  7. **最终调试 (Commission)**
- 每个阶段包含阶段目标、文件交付物下载区、业主确认/驳回按钮。

## 4. 技术与设计规范

### 4.1 核心设计语言
- 继承 `App.json` 中定义的主题色：背景白 `#ffffff`，强调色 `#007AFF` (Apple 蓝)，文字辅助色 `#999999`，底色 `#f2f2f7`。
- PC 端采用侧边栏或顶部顶级导航，保证大屏留白；H5 端采用底部 TabBar 逻辑。

### 4.2 路由与页面映射策略
在开发 Web 前端时，应将小程序的 `pages/xxx/xxx` 扁平化映射为 Web 路由。例如：
- 小程序 `pages/products/products` -> Web `/` 或 `/home`
- 小程序 `pages/course/index/index` -> Web `/courses`
- 小程序 `pages/mall/product-detail` -> Web `/mall/product/:id`
- 小程序 `pages/designer-home` -> Web `/designer/hub`

### 4.3 高优先级核心交付模块 (Web MVP)
为保证项目顺利迁移，建议首批交付的 Web 端 UI 包含：
1. **公共与导航**：首页、公共顶部导航栏。
2. **认证模块**：登录/注册及身份选择页。
3. **专业工具**：照度计算器页及色温推荐报告页（PC大屏优势明显）。
4. **设计师工作台**：需求大厅及项目详情跟进页（便于上传附件）。
