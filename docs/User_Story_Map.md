# 用户故事地图 (User Story Map) - 光乙共创平台 Web 端

## 1. 用户故事地图概述
本文档以可视化的层级结构描述了光乙共创平台 Web 端在不同用户角色下的核心业务流程与功能拆解。旨在帮助团队俯瞰产品全貌，理解用户在平台上的任务流，并指导开发迭代的版本规划。

---

## 2. 角色定义
- **普通用户 (User/业主)**：来平台寻求灯光灵感、购买灯具、学习课程、发布设计需求。
- **照明设计师 (Designer)**：使用专业工具，在平台承接设计需求并进行大文件交付。

---

## 3. 用户活动流 (横向) 与 任务分解 (纵向)

### 主轴 1：内容探索与灵感发现
**用户目标**：了解照明知识，寻找装修灵感。

- **活动 1.1：浏览首页与服务说明**
  - **MVP**：作为用户，我可以在 PC 上浏览全屏的 Apple 风格品牌主页与服务说明长图，了解平台的专业性。
  - **v2.0**：作为用户，我可以一键将服务说明导出为 PDF 分享给家人或合伙人。

- **活动 1.2：探索灵感库**
  - **MVP**：作为用户，我可以通过瀑布流浏览高清灯光实景图。
  - **MVP**：作为用户，我可以通过多维筛选（空间/风格/色温）快速定位参考图。
  - **v2.0**：作为用户，我可以点击图片放大查看，并将喜欢的图片加入“我的灵感看板(Moodboard)”。

### 主轴 2：专业工具赋能
**用户目标**：获得准确的照明参数指导。

- **活动 2.1：使用 AI 色温助手**
  - **MVP**：作为用户，我可以与 AI 对话，输入我的空间情况，获取 GLM 推荐的色温方案。
  - **v2.0**：作为用户，我可以将 AI 生成的方案保存为本地文本或直接转换为需求单草稿。

- **活动 2.2：使用照度计算器**
  - **MVP**：作为用户，我可以使用免费版表单快速计算单一房间的照度。
  - **v2.0**：作为设计师，我可以使用 Pro 版计算器，利用大屏优势展示复杂表格，并使用快捷键批量添加灯具。
  - **v2.0**：作为设计师，我可以一键生成 A4 排版的计算报告 PDF 供打印。

### 主轴 3：电商与课程消费 (商业变现)
**用户目标**：购买物理商品、软件权限或知识服务。

- **活动 3.1：购买灯具与工具包**
  - **v2.0**：作为用户，我可以在 Web 端将商品加入购物车并批量结算。
  - **v2.0**：作为用户，我可以使用微信扫码或支付宝完成 Web 支付。
  - **v2.0**：作为用户，我可以在个人中心查看订单物流状态并申请退款。

- **活动 3.2：学习灯光设计课程**
  - **v2.0**：作为学员，我可以在大屏幕上流畅观看高清课程视频。
  - **v2.0**：作为通过白名单导入的学员，我使用手机号登录后即可免支付观看课程。

### 主轴 4：设计服务撮合与协作 (双边市场)
**用户目标**：业主找到好设计，设计师完成高质量交付。

- **活动 4.1：发布需求与匹配**
  - **v3.0**：作为业主，我可以在 Web 端填写详细表单，上传户型 CAD 图发布需求。
  - **v3.0**：作为业主，我可以支付押金让我的需求获得“优先”标志。
  - **v3.0**：作为设计师，我可以在“需求大厅”接单面板筛选并抢单。

- **活动 4.2：项目协作与交付**
  - **v3.0**：作为设计师，我可以通过 Web 端上传体积较大的 DIALux 源文件和全套渲染图。
  - **v3.0**：作为业主/设计师，我们可以通过“阶段交付 Kanban”查看项目的进度流转（勘测-布灯-验收）。

---

## 4. 故事优先级与版本映射

| 横向活动流 | MVP (Phase 1) | v2.0 (Phase 2) | v3.0 (Phase 3) |
| :--- | :--- | :--- | :--- |
| **内容与灵感** | 官网建设、基础图库、基础搜索 | 高级筛选、用户收藏看板 | 内容评论与社区互动 |
| **专业工具** | AI助手、免费计算器 | Pro版计算器、PC快捷操作、PDF报告 | 工具历史云端同步 |
| **电商与课程** | 课程大纲展示 (引导回小程序) | 完整扫码支付、课程视频播放、订单管理 | 课程笔记功能、发票申请 |
| **服务与协作** | 静态服务说明引导 | 基础需求表单发布 | 完整接单看板、大文件上传、阶段流转 Kanban |
